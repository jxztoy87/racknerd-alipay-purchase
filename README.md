## 支付宝续费和几个常见疑问

到这一步，最核心的"RackNerd 支不支持支付宝"已经回答完了。但实际用起来还会冒出几个边角问题，下面统一说。

**续费还能用支付宝吗？**

能。续费走的也是同一套支付通道，到账单管理那里手动续费，照样能勾支付宝。开自动续费的话，系统默认会用首次下单的方式扣，支付宝这种扫码付的方式不能自动扣，所以用支付宝的最好把自动续费关掉，设个日历提醒自己手动续，免得忘续了机器被停。我自己就是手动续，到期前一周邮箱会收到提醒邮件，扫一下码几分钟搞定。

**支付宝付款有汇率差吗？**

支付宝按实时汇率折算人民币，跟你在支付宝里看到的美金兑人民币牌价基本一致，不会有额外的兑换手续费。单笔金额大的时候，可以对比一下银联的汇率，哪个划算用哪个。日常小单子差别不大，不值得为这个纠结。

**支付宝付款有限额吗？**

限额看的是支付宝账户本身那个，跟 RackNerd 没关系。普通账户单笔几千块人民币没问题，年付 $119.99 这种折合人民币 800 多块，完全在常规额度内。大额独立服务器月付可能上千美元，那种就得多留意下自己支付宝的单笔/单日限额，不够的提前提额或者分笔付。

**付完多久能开通？**

KVM VPS 是即时开通的，支付宝扫码付完几分钟内机器就上线，开通邮件跟着到。独立服务器因为是物理机，要人工上架配 IP，通常几小时到一天不等，这个跟支付方式无关。

**能不能退款？**

这点要分开说。特价年付套餐（VPS Specials、新年特惠那些）本身价格就压到底了，按 RackNerd 的惯例这类一般是不退的，下单前自己想清楚配置够不够用。标准按月套餐的政策相对宽松些，具体以开通时服务条款里的说明为准。我自己买过几单特价套餐，用着没问题也没动过退款，所以这块没法给你拍胸脯说具体几天内能退——下单前花一分钟看下服务条款那一栏最稳妥。
